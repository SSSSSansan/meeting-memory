# Доля казахской речи в наборе

Источник: чистые транскрипты `data/raw` (по сегментам), 14 встреч из `world.yaml`. Скрипт: `scripts/language_share.py`.

## Метод

Оценка по буквам и частым словам, не разметка. Реплика = сегмент транскрипта.
- **Реплика с казахскими буквами** — есть хотя бы одна из `ә ғ қ ң ө ұ ү һ і` (кроме имён Нұралы, Сандуғаш, Қамқор).
- **Казахское слово** — в слове есть такая буква или оно в списке частых казахских слов без особых букв (55 слов: «ол», «керек», «деп», «бар», «сосын» и т. п.); общие для ru и kk слова в список не входят. Знаменатель — все слова (латиница и русские тоже).
- **Встреча содержит казахскую речь**, если доля реплик с казахскими буквами **или** доля казахских слов не меньше 10,0%.
- Оценка занижена для казахских слов вне списка и русско-казахских омонимов.
