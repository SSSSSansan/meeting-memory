# Ручная разметка фактов (калибровка судьи по фактам, A8)

Файл для разметки: `sheet.csv` (utf-8-sig, открывается в Excel; можно сохранять с разделителем «;»). Заполнить колонку `human` и при желании `comment`. Остальные колонки не менять.

Каждая строка — один ответ системы (`system_answer`) на вопрос (`question`) и один факт из эталона (`fact`). Строки одного ответа имеют общий `label_id`.

## Что ставить в `human`

| `fact_kind` | `1` | `0` |
|---|---|---|
| `required` | факт **есть** в ответе | факта в ответе нет или он другой (другая дата, число, человек) |
| `forbidden` | ответ **утверждает** это (прямо или по смыслу) | ответ этого не говорит, не упоминает или отрицает |

- Сравнивать **по смыслу, не дословно**: другие слова, казахский вместо русского, другой порядок — это всё ещё тот же факт.
- Частичное совпадение для `required` — это `0` (например, срок «до 4 сентября», а в ответе «в сентябре»).
- Вопросы, на которые в данных нет ответа: `required`-факт вида «в данных нет …» = `1`, если система честно отказалась («в контексте нет информации …»), и `0`, если она выдумала ответ.
- Служебные пометки вида «(Удалено неподтверждённых цитат: N …)» и ссылки на встречи — не утверждения ответа.
- Пусто — строка не размечена и в подсчёт не идёт. Другие значения, кроме `0` и `1`, скрипт подсчёта не примет.
- Сомневаешься — поставь лучшее, по-твоему, значение и напиши почему в `comment`.

## Правила

- Не открывать `key_private.csv` до конца разметки: там вердикт судьи, тип вопроса и `question_id`.
- Размечать по порядку `row_id`.

## Подсчёт

```bash
python scripts/score_facts_calibration.py
```

Модель не вызывается: сравнение `human` с `judge_value` из `key_private.csv` (вердикт judge-facts-v1 из прогона `results/eval_20261114_0935.json`). Результат — `agreement.md` в этой папке: % совпадения и Cohen's kappa по required, forbidden и в целом, матрицы ошибок, список расхождений, fact_f1 по ручной разметке против судьи.

Пересборка листа: `python scripts/make_facts_sheet.py` (сид 42, детерминировано; **затирает** заполненный `sheet.csv`).
