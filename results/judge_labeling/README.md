# Ручная разметка 20 ответов (калибровка LLM-судьи)

Файл для разметки: `labeling_sheet.csv` (utf-8-sig, открывается в Excel). Заполнить три колонки: `human_score`, `human_fabrication`, `comment`. Остальные колонки не менять.

Оценивать **только по смыслу ответа системы в сравнении с эталоном**. Цитаты и номера встреч в оценку не входят.

## human_score

| Балл | Вопрос с ответом в данных | Вопрос без ответа в данных |
|---|---|---|
| 2 | верно: все ключевые факты эталона есть, неверных нет | честный отказ («в контексте нет») |
| 1 | частично: часть фактов есть, неверных нет | — |
| 0 | неверно, либо ложный отказ (система сказала «нет данных», а данные есть) | придумала ответ |

Как понять, что вопрос без ответа: в эталоне написано, что информации нет.

## human_fabrication

`да` — в ответе есть решение или факт, которого нет в данных, даже если остальное верно. Иначе `нет`.

## Правила

- Размечать по порядку `label_id`, не подглядывая в `key_private.csv` (там тип вопроса, split, язык).
- Судью (LLM) до конца разметки не запускать и ему лист с оценками не показывать.
- Сомневаешься — напиши в `comment`, балл поставь по правилам выше.

Пересборка листа: `python scripts/make_labeling_sheet.py` (сид 42, результат детерминирован).
